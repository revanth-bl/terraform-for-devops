## 📖 About

Terraform is one of the most widely used **Infrastructure as Code (IaC)** tools for automating cloud infrastructure.

Instead of manually creating cloud resources through the AWS Console, Azure Portal, or GCP Console, Terraform allows you to define your infrastructure using code.

This repository is designed to help beginners and intermediate engineers master Terraform through structured notes, examples, diagrams, and real-world projects.
